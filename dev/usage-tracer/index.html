Usage tracer

Send one model request on the dev cluster and follow it. The request itself only touches the gateway and the model. Metering happens after the response, from a log record the gateway writes, so it can't slow a request down or block it. Every step below is a real lookup: the dark block is the command the tracer ran, the light block is what came back.

The first API-key request mints a key. The gateway refuses it (403) until it has loaded the key, so that send takes longer.
